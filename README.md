The Library Management System (LMS) is a console-based application built in Python that allows librarians and users to manage library operations efficiently. The system provides the ability to:

-> Add new books to the library database.
-> Search and display book details.
-> Borrow and return books.
-> View all available books.
-> Handle errors gracefully using exception handling.
-> Store all data in files (book records, user actions) for persistent storage.

Features
Add Books: Add new books to the library catalog with details like book title, author, and ISBN number.
Search Books: Search for books by title, author, or ISBN number.
Borrow and Return: Users can borrow available books and return them when finished.
Book List: View all the books available in the library.
File Handling: All book data is stored in text files for persistence.
Exception Handling: The system uses exception handling to ensure smooth operation, managing file errors and invalid input.

Technologies Used
Python : Core Python for file handling, exception handling, and logic implementation.
File Handling: Reading and writing book records to text files.
Exception Handling: Ensures graceful error management when interacting with files or invalid user input.
